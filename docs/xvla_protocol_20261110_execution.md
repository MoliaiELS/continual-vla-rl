## E1 评估与成本校准

19528、19532 已提供 B0 原生源开发结果 9/10 与 16/20，合计 25/30。原生历史与 PPO 使用的实测 proprio/history 路径分别记录。共同部署评估应固定 flow 初始噪声 seed，关闭附加终端探索噪声，并与原生诊断使用相同状态和 seed。在线训练信号校准保留 PPO 的附加终端探索配置。两种评估的成功率、有效控制步及超时应各自报告。评估和 reset 不占训练控制步预算，仍分别登记墙钟和 GPU 成本。

19569 在 A 的初态 10–29 使用部署路径，和 19532 原生回合逐一核对初态摘要、环境 seed 及 flow seed。两者均为 16/20，二元结果逐回合一致，实际控制步分别为 4,331 和 4,330。19569 用 0.062896 GPU 小时。19570 在初态 30–39 使用在线探索配置，10/10 成功并实际执行 726 个控制步，用 0.023138 GPU 小时。该信号仅覆盖三组 pilot 共同使用的标准训练池。九个几何偏移开发初态已有原生可解性证据，尚无同配置的在线信号结果。

CPU 作业 19572 完成 50 个标准初态与 10 条原始示教首帧的物理核对，退出码 0:0。各池之间无相同状态摘要，静置前后均无 1 mm 内的物体中心重合，无初态在策略执行前满足任务谓词。十个独立源测试候选与其它池的最小任务相关物体中心差约 5.34 mm。检查覆盖物体中心，旋转和轨迹留待后续分析。审计未运行策略，封存候选的逐态坐标也未导出。报告为 `runs/19572/e1_source_audit.json`。首跑 19571 因登记的示教清单摘要录入错误以 1:0 退出，校正使用原文件摘要，数据及权重身份一致。已有 PPO smoke 耗时仅用于估算和核对环境。本轮长程吞吐以实际预算 pilot 为准。

## E3 正式矩阵

SFT-cont 从同一个 19525 出发，使用相同三组 seed 和原来的十条示教，每组用新优化器追加 2,048 次更新，评估 512、1,024、2,048 三个节点。先串行跑完 SFT-cont，再按 seed 顺序串行派发 B1、B2、M。使用 `tools/xvla/remote.ps1 e3-status` 查看调度器记录。E3 阶段的当前评估只使用任务 0 的开发初态。
