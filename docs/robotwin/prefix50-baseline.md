# X-VLA RoboTwin 2.0 每项 50 回合基线

2026-11-21 决定缩减本轮评测规模，以更快完成冻结基线。Easy 和 Hard 均保留官方 50 个任务。每任务按已固定的初态清单顺序选取索引 0–49，每种条件合计 2,500 个回合。剩余 Hard 扩测从本轮交付计划移除。此项调整发生在原计划已开始之后，报告中注明调整时间和原因。

Easy 使用原 300 动作预算的已完成记录重算前 50，不额外运行 GPU 作业。保留原预算的首批 5,000 和累计 7,000 回合结果，也保留五任务原生预算的独立 900 回合。Hard 沿用各任务 400–1,700 个原生动作上限、原模型和成功判定。Easy 与 Hard 的动作预算差异需标注在结果表中。

Hard 复用前 50 范围内已经完成且通过验证的策略回合。已有超出前 50 的回合继续保存在原始日志。预筛仍按原方案分段完成完整冻结清单，以保持 seed、场景校验和 `seed_manifest.json` 的既有证据身份。缩减的是策略评测回合数。后续恢复跳过已经完成的种子。

每任务报告成功数、完成数和 Wilson 95% 置信区间，全部 50 项完成后按任务等权平均。未完成任务和技术错误单独显示。样本数从 100 减为 50 后，50% 成功率附近的每任务 95% Wilson 区间由约 40.4%–59.6% 变宽到 36.6%–63.4%。

论文可将其描述为受计算预算约束的基线评测。官方 RoboTwin 2.0 文章使用每任务、每条件 100 回合。Open-HumanWAM 预印本也采用 50 回合进行部分评测，官方排行榜部分采用 100 回合。报告应把本项目的缩减评测标成独立口径，官方数字仅作参考。 [RoboTwin 2.0 §4.5](https://arxiv.org/html/2506.18088v2#S4.SS5) · [Open-HumanWAM §5.5](https://arxiv.org/html/2611.06817v2#S5.SS5)

方法章节可采用以下表述。

> 为在可用计算预算内完成基线评测，我们在 RoboTwin 2.0 的 50 项任务上，每个难度报告 50 个回合，按冻结初态清单的顺序取前 50 个。该样本量调整发生于初始评测启动后。Easy 每回合最多执行 300 个动作，Hard 使用各任务的原生动作上限。我们报告每任务成功率和 95% Wilson 区间，并对 50 项任务等权汇总。
