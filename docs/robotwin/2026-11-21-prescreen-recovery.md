## 扩测的内容和目的

动作预算扩展和样本扩测是两件事。当前 Hard 的动作预算按每项原生上限固定为 400–1,700；样本扩测则在相同预算、模型和成功判定下增加不同初态。

全部 50 项先各跑 100 回合，共 5,000。预定重点任务各再跑两批 100 回合，累计各 300，新增 2,000，总计划 7,000。重点任务为：

| Task ID | 内容 |
| --- | --- |
| `move_stapler_pad` | 把订书机搬到垫子 |
| `turn_switch` | 操作开关 |
| `click_alarmclock` | 触碰闹钟顶部按钮 |
| `move_pillbottle_pad` | 把药瓶放到垫子 |
| `move_can_pot` | 把罐子移到锅中 |
| `open_microwave` | 打开微波炉门 |
| `pick_dual_bottles` | 双臂抓取两个瓶子 |
| `lift_pot` | 双臂抬锅 |
| `place_bread_basket` | 把面包放入篮子 |
| `press_stapler` | 按压订书机 |

每项重点任务的 300 个专家有效初态先按固定候选顺序预筛并冻结；先评测前 100 个，50 项首批全部完成后才运行后两批。追加的 200 个是不同初态，不是前 100 个的重复回放。任务和初态选择保持预定规则。

扩测用于减小每任务成功率的抽样波动，检查低成功率、偶然成功或异常敏感性是否稳定，为后续强化学习的前后对照提供更可靠基线。例如成功率约 50% 时，100 回合的 95% Wilson 区间约为 40.4%–59.6%，300 回合约为 44.4%–55.6%。这只是样本量作用的统计示例，不是当前任务成功率。

评测期间权重冻结，不执行训练或奖励更新。报告独立展示首批、扩测和累计；总体及类别继续按任务等权，十项重点任务不会因采样三倍而取得三倍权重。
