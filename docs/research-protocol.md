# 共享 VLA 持续强化后训练实验方案

更新：2026-11-04。将长任务序列、简单经验回放、遗忘指标与分层 OOD 评估纳入后续研究。交互效率仍为主目标，能力保持与迁移分别验证。当前已完成单任务真实 GRPO 更新、保存及独立重载；以下扩展是实验协议，尚未实施或运行。

本方案衔接 [部署入口](deployment.md) 与 [单任务验收记录](deployment-validation-20261104.md)，依据 [Notion 研究主线](https://app.notion.com/p/409d26c2767d81129f01e80b77d2e2bc) 和本次文献补充。两任务 Seq/Joint 保留为工程验收，正式持续学习研究使用更长序列。

## 文献结论与研究假设

| 来源 | 与本实验有关的证据 | 对协议的影响 |
| --- | --- | --- |
| [Simple Recipe Works v3](https://arxiv.org/html/2603.11653v3#S4.SS4.SSS3) | 第 4.4.3 节将序列扩大到 30 个任务，仍报告较好的保持；其主实验的简单 ER 也没有普遍优于 Seq | 检验长度、任务差异与预算的作用，保留强 Seq 基线；不预设必须出现遗忘或 ER 收益 |
| [DyGRO-VLA](https://proceedings.mlr.press/v306/lin26af.html) | 研究跨任务在线优化干扰，使用冻结基座的残差专家；其任务规模实验与共享 LoRA 的顺序 GRPO 设置不同 | 将任务规模与异质性纳入压力测试，分别解释联合干扰和顺序遗忘 |
| [Pretrained Vision-Language-Action Models are Surprisingly Resistant to Forgetting in Continual Learning](https://proceedings.mlr.press/v306/liu26bu.html) | 连续模仿学习中，小规模 ER 可以显著帮助预训练 VLA 保持能力 | 增设简单 ER 对照；其收益需要在本项目在线 GRPO 条件下重新验证 |

研究问题是：同一起点与明确成本下，随着任务序列延长，哪些既有能力发生退化？均匀有限回放能否改善保持，同时维持新任务学习与单位交互收益？这种变化对不同曝光历史和分布偏移的评估任务有何影响？

任务数量增加本身不等于任务差异增加。分别记录任务族、初始能力、语义/动作相似性和顺序；同质 Spatial 序列与跨 suite 序列分开分析。

## 分阶段运行

| 阶段 | 工作 | 验收或进入下一阶段的条件 |
| --- | --- | --- |
| E 两任务 | Spatial 0、1 的 SFT / Seq / 均衡 Joint；补齐计数器与阶段衔接 | 实际预算正确、按组任务分配正确、保存重载可靠、逐任务评估完整 |
| F 五任务 | 同一 Spatial SFT 起点，比较 Seq、Seq+ER、Joint、Joint+ER | 原协议与 ER 各通过短测；每个训练阶段均有能力矩阵和成本记录 |
| G 长序列 | 先计划 10 个任务，再按可用共同起点与资源扩到 20/30 个任务 | 长序列的共同 base、动作接口、数据曝光与独立留出集合明确 |
| H OOD | 在开发集诊断，在冻结方法后评估最终集合 | SFT/RL/回放曝光分层、任务变换与最终集合均预先冻结 |

阶段 F 先用单种子排查实现与信号，核心结论争取至少三个训练种子。跨方法配对相同任务顺序与种子。长序列至少包含固定参考顺序及预定置换，报告顺序敏感性；不必立刻展开所有方法、顺序、长度、预算的完整网格。

### 任务池与序列长度

1. 五任务的开发候选仍可用 Spatial 0–4；具体划分在能力预检查后冻结。此前 0–4 / 5–6 / 7–9 是未执行的示例，不作为不可变的正式划分。
2. 若保留 Spatial 内的 RL 留出任务，训练序列就不能同时包含全部 10 个 Spatial 任务。若采用全 Spatial 的 10 任务协议，应在运行前另设独立留出池，记录这是新协议。
3. 20/30 任务需要新的任务池与共同起点核查。所有阶段继续同一个 base 与累计 adapter，不能在 Spatial/Object/Long 之间换用各自的 suite SFT checkpoint。
4. 当前 Spatial checkpoint 可作为跨 suite 能力预检查的候选起点，但尚未证明适合全部新任务。需核实动作反归一化统计、任务接口及初始成功；不能仅凭存在另一个 suite 配置就宣称可行。
5. 若需要重做共同 SFT，固定该 SFT 数据、曝光表和 snapshot，并让该组所有方法重新从同一起点开始。原 Spatial 起点实验单独保留。

长度实验使用嵌套任务列表，例如长序列的前 5、前 10 个任务。固定每任务预算时，前缀内任务、训练量与初态分布匹配；固定总预算时，明确每任务 B/N 的变化，并从共同起点独立运行，不能把已花完 B 的五任务 checkpoint 继续训练后当作十任务的等总预算结果。顺序置换不能通过最终评估分数挑选。分别报告不同任务数和训练阶段数；将 5 个任务重复三遍是 15 个阶段、5 个不同任务。

如保留现有 7–9 留出候选，Spatial 内可先用五任务再扩到七个不同训练任务，作为进入跨 suite 长序列前的过渡。原开发任务一旦转入训练，需要重新标注角色。

### 预算需要两种视角

| 视角 | 固定项 | 回答的问题 |
| --- | --- | --- |
| 固定每任务训练量 | 每任务策略控制预算 b、阶段训练规则；总预算为 N×b | 旧任务在更多后续训练之后如何变化 |
| 固定总交互 | 总预算 B、任务宏平均目标；随 N 增加，每任务可用预算减少 | 有限预算下任务覆盖、保持与学习的取舍 |

固定总预算下，任务越多可能只是每任务练习不足；不能把这种最终低分直接解释为遗忘。NBT 必须参照该任务刚学完时的分数。

当前 K8/G1/R1/H512 配置每采集周期名义控制步为 4,096。此前两任务 10+10 周期与 Joint 20 周期的 81,920 步仅是起步预算示例。正式 b、B 根据吞吐、开发学习曲线和总资源在比较前确定。

所有方法记录实际 policy_env_steps；全败/全胜组、重采样、失败尝试与首次成功后的继续执行都计入采集成本。settling/reset、评估调用、人工/示范数据、BC 样本呈现次数、优化步数、GPU 时间和墙钟另列。成功后的 mask 不会退还已经执行的环境步。

## 最小方法矩阵与回放语义

| 方法 | 在线采集 | 辅助数据 |
| --- | --- | --- |
| SFT | 无 | 固定共同起点，提供 S0 |
| Seq | 按任务阶段顺序执行 | 无 |
| Seq+ER | 与 Seq 相同 | 对已学任务的有限记忆均匀回放 |
| Joint | 按任务均衡的组采样 | 无 |
| Joint+ER | 与 Joint 相同 | 从开始可访问全部 Joint 训练任务示范，在相同总容量下均匀回放 |

Joint 是始终可以访问训练任务集合的参照，其数据可用性与严格顺序学习不同。Joint+ER 的上述示范准入是联合训练参照的明确选择；如另做首次在线遇到任务后才准入的版本，需要单列。记忆准入规则、可访问示范与容量必须逐方法列出，最终留出始终排除。

第一版 ER 使用独立 BC 辅助损失：

\[
L=L_{\mathrm{GRPO}}+\lambda_{\mathrm{BC}} L_{\mathrm{BC}}(M).
\]

旧轨迹不直接混入当前 GRPO 冒充本轮 on-policy 数据。原 GRPO 的奖励、分组、mask、LoRA rank、chunk 和动作处理沿用已验收配置。

记忆来源明确选择并分别命名：

- **专家示范 ER**：Seq+ER 第一版候选。在学习阶段 j 时，只回放 i<j 的已学任务；某任务阶段完成后，才将其指定示范加入后续记忆。记录示范 ID、来源及是否与原 SFT 重合；没有作者逐轨迹清单时，重合状态记为 unknown。
- **自身轨迹回放**：后续独立分支，可将过往成功轨迹用于 BC。其数据质量、成功选择与额外交互条件不同，单独报告。
- **SFT 先验维护**：若从开始就允许回放全部 SFT 任务，单独命名为 prior rehearsal；这会使未来任务提前获得本轮训练曝光，不能叫严格的 seen-task-only ER。

专家示范能给 ER 增加监督信息。报告方法间可访问数据集合；另用 BC 权重为零的相同数据准入配置，区分数据可用性与实际使用。若进一步比较回放分配算法，则固定数据池、总容量、BC 权重与呈现次数，仅改变选择策略。

长序列的主回放容量采用固定总容量 M，按动作 chunk 样本数及实际字节记录，明确任务间均衡与淘汰规则。每任务固定 m、容量随任务数增长的设置作为另一对照，不能称固定总记忆。轨迹条数也记录，但不同长度轨迹不能直接当成相同容量。

### 现有 ER 入口需要先修正

`rlinf/custom/libero_trajectory_dataset.py` 的 `LiberoSFTDataset` 当前枚举 suite 目录全部 `.hdf5`，没有按已学任务过滤；`fsdp_actor_worker.py` 以每任务 1 条示范初始化该数据集。因此直接打开 `use_experience_replay` 可能引入未来任务或留出任务。

接入前必须增加显式 task allowlist 与数据 manifest，在每次阶段切换时更新准入；运行时导出实际任务/示范 ID。断言训练与回放集合均不含最终留出，并在阶段开始前检查未来任务没有提前进入记忆。原论文的 ER 与本项目 seen-task-only ER 如信息条件不同，分别标注。

ER 的当前双卡执行路径尚未验收。短测需检查 BC 输入和动作标签一致、辅助梯度有效且有限、总 loss 与显存合理、保存重载可靠。单任务 GRPO 通过不能代替 ER 通过。

## 能力矩阵与指标

定义 S[i,j] 为完成第 i 个任务阶段后，在任务 j 上的成功率；S[0,j] 为共同 SFT 起点。每个阶段保存累计 adapter 和预算，并评估相同的预定任务、初态与采样协议。分别保存 S_ever 与 S_final，不把两种成功判据混算。

沿用 [Simple Recipe 附录 B](https://arxiv.org/html/2603.11653v3#A2) 的终局定义，设序列长度为 N：

\[
\mathrm{NBT}_{\mathrm{final}}=\frac{1}{N-1}
\sum_{j=1}^{N-1}(S[j,j]-S[N,j]).
\]

正值表示净退化，负值表示后续训练带来净改善；不取绝对值或截成非负。最后一个任务没有后续阶段，不进入分母。若成功率从 80% 降到 60%，该项为 20 个百分点。NBT 是行为表现变化，不单独证明知识表征已被删除。

阶段曲线使用同样规则得到 NBT(k)，并报告每个任务的下降，防止正负变化在平均值里相互抵消。若与 [持续模仿学习论文的时间平均定义](https://arxiv.org/html/2603.03818v2#S3.SS1) 比较，另报以下明确排除末任务的版本：

\[
\mathrm{NBT}_{\mathrm{time}}=\frac{1}{N-1}
\sum_{j=1}^{N-1}\frac{1}{N-j}
\sum_{i=j+1}^{N}(S[j,j]-S[i,j]).
\]

两种聚合不能混用同一个标签；跨论文复核各自聚合和分母约定。归一化 NBT 不作为首轮主指标，避免 S[j,j] 接近零的分母问题。

五任务优先完成全部阶段能力矩阵。长序列的下三角评估量随 N(N+1)/2 增长，需单独预算；终局 NBT 只需各任务对角线与最终行。若资源仅够这些评估和少量检查点，则报告终局 NBT 与稀疏曲线，不声称测得完整时间平均 NBT。所有阶段仍保存 checkpoint，以便按预定计划补评。

同时报告：

- 最终任务宏平均、最弱任务、逐任务结果及随实际控制步的 AUC。AUC 使用预定的固定任务面板或分别报告逐任务曲线，不以阶段间不断变化的“已学任务均分”直接比较 Seq/Joint。
- 新任务刚学完时的能力与增益，排除“不学习所以不遗忘”。
- 零样本 FWT：按 Simple Recipe 定义为 (1/(N-1)) × sum_{j=2..N}(S[j-1,j]-S[0,j])；这里的“未来”指尚未参加本轮 RL，不能与相对单任务训练基线的其他 FWT 定义混用。
- 每任务最大下降和超过预定容忍阈值的任务比例；可另报相对历史最佳检查点的遗忘，明确其与 NBT 的区别及评估噪声影响。
- 分层 OOD 的起点、终点和差值，而不只给终点高分。
- groups_kept/groups_collected、组内回报方差、有效训练步、每单位控制步保留的有效组数。

NBT 依赖各任务刚学完的阶段，主要用于 Seq 与 Seq+ER。Joint 没有唯一的“任务 j 刚学完”时刻，主报统一预算下的任务曲线、AUC 与最终表现，不人为套用 Seq 对角线。

正式结果同时记录训练种子与评估不确定性；任务宏平均先按任务统计再聚合。配对方法使用相同评估种子与初态；跨训练种子的波动与单个 checkpoint 的评估误差分开报告。评估集合与次数事先确定。

优化器状态在阶段切换时是否保留，需要在协议中固定。现有 adapter 加载只恢复权重；若沿用作者包装器的重建优化器方式，标注此行为，并以保留状态或匹配重置的对照检查其影响，不能将差异全部归于任务顺序。

## 按曝光与偏移分层评估

OOD 必须说明相对于哪一个训练分布。任务是否参加 RL、是否出现在适配 SFT、是否经历视觉/物理偏移是不同维度，不能合并成一个总 OOD 分数。

| 集合 | 适配 SFT 曝光 | 本轮 RL/BC/蒸馏训练曝光 | 问题与候选 |
| --- | --- | --- | --- |
| A 既有任务的 RL 留出 | 有 | 无 | Spatial 中预留的任务，检查既有能力保持或跨任务收益 |
| B 适配 SFT 未见任务或组合 | 有证据排除目标任务/组合 | 无 | 同一动作接口下的新目标组合或跨 suite 候选，检查任务/组合泛化 |
| C 分布偏移 | 单独标注 A/B 属性 | 目标变换无 | 相同任务在新相机、光照、背景或物体/机器人初态范围下的鲁棒性 |
| U 曝光未知 | unknown | 无 | 可以报告表现，但不归入严格的 SFT-unseen 结论 |

A 是相对本轮 RL 的留出；当场景分布相同时，不必将其称为严格分布外任务。Spatial SFT 已覆盖 suite 任务，单纯换到另一个 Spatial ID 不构成 B。

B 优先保证“适配 SFT 未出现的完整任务或组合”可核实。没有出现在本次 Spatial SFT，不等于 OpenVLA 的机器人预训练、VLM 预训练或其他祖先数据从未包含相关对象/技能。只有数据谱系证据支持时才称全训练历史未见；否则使用更窄的命名。若需要严格控制，建立带数据清单的共同 SFT 与组合留出，所有比较方法使用同一起点。

C 的相机/光照/位置变体可利用本仓库已有入口，但需核实实际仿真参数确已改变；仅修改 benchmark 名称不证明分布偏移生效。分别固定偏移类型与幅度，一次改变一个因素，再考虑组合偏移。新的随机种子若仍来自原分布，只是独立评估样本。

### 未见任务与非零起点能力

“未见过该完整任务”与“能够借助已有组件技能偶尔成功”并不矛盾。先在开发候选上，用预定数量初态/种子评估 SFT，报告成功次数、样本数和区间；少量零成功不足以证明真实成功率为零。

若关注已有泛化能力的保持，可以预先定义 base-solvable 子集的筛选规则，并报告完整候选池与筛选成本。开发集用于检验这条规则；最终集合按独立任务/组合和种子冻结，不依照方法终评收益挑选。可由冻结的 base-only 校准建立最终子集，但校准结果不反馈方法开发，且同时报告完整最终池。

OOD 只做评估时无需满足 GRPO 混合成功组条件；若将某候选纳入在线 RL，才进一步验证组内奖励差异。严格 OOD 的起点接近零时，结果容易出现地板效应，需要与可解子集分层解释。

每个评估任务建立曝光记录：任务/组合与变换定义、资产哈希、机器人预训练和适配 SFT 的 yes/no/unknown 及证据、本轮 RL、BC、蒸馏、数据选择使用情况、开发/最终角色。动作归一化统计也记录来源、冻结时间及未来/留出数据是否参与；起点自带统计属于公共固定先验。最终任务不参与调参、采样调度、回放、成功轨迹筛选或 checkpoint 选择。任何上述训练使用发生后，应重新标注该任务身份。

## 下一批交付

1. 完成两任务的逐任务累计预算、均衡组采样与能力矩阵导出，保持当前已验收的模型/奖励路径。
2. 建立开发任务与曝光表，冻结五任务试验的任务池、预算、记忆来源和评估协议。
3. 实现 seen-task-only 的有限均匀 ER，通过辅助损失和数据准入短测。
4. 运行五任务 Seq / Seq+ER，并配置匹配的 Joint 参照；输出阶段能力热图、NBT 与预算曲线。
5. 再决定 10/20/30 任务共同起点与分层 OOD 的正式规模。所有长仿真、评估和训练继续通过 Slurm，在固定 commit worktree 上运行。

本方案只增加实验对照与可验证口径。简单 ER 本身是基线，后续方法贡献需要在同预算、同记忆和同曝光条件下超越它；若强 Seq 已经保持良好，研究重点继续放在交互效率、任务覆盖与迁移边界。
